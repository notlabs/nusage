# help: pack
Bundle files

Usage:
  > pack {flags} ...(file) 

Flags:
  -h, --help: Display the help message for this command
  -t, --tag <list<string>>: Tag to attach, repeatable (default: [])
  -v, --verbose <int>: Log more, repeatable (default: 0)
  --format <string>: Archive format (default: 'tar')

Command Type:
  > custom

Parameters:
  ...file <path>: Files to bundle

Input/output types:
  ╭───┬───────┬────────╮
  │ # │ input │ output │
  ├───┼───────┼────────┤
  │ 0 │ any   │ any    │
  ╰───┴───────┴────────╯
