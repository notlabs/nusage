# help: greet
Greet someone

Usage:
  > greet {flags} <name> 

Flags:
  -h, --help: Display the help message for this command
  -l, --loud: Shout the greeting
  --times <int>: How many times to greet

Command Type:
  > custom

Parameters:
  name <string>: Who to greet
